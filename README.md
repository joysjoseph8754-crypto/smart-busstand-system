
# Smart Bus Stand System

IoT Based Smart Bus Stand Monitoring System.

## Project Description
The Smart Bus Stand System is designed to improve passenger convenience and bus stand management using IoT technology.

## Components Used
- Arduino
- IR Sensors
- LCD Display
- Buzzer
- LEDs

## Features
- Passenger monitoring
- Bus arrival indication
- Smart monitoring system

## Technology Used
- Arduino
- Embedded C
- IoT
